# 游戏方案

## 核心玩法

唐僧位于地图中央，拥有生命值。妖怪从地图边缘沿路径接近并攻击唐僧；玩家在指定格子放置防御角色，角色自动攻击。每波结束后从随机出现的三个升级中选择一个，形成不同的战斗组合。

第一版以三波战斗验证放置、自动战斗和升级选择是否有趣。唐僧生命值归零则失败，消灭第三波所有敌人则胜利。

## 第一版内容

- 孙悟空：攻击范围内最近的敌人，造成范围伤害。
- 猪八戒：近战攻击并阻挡靠近的敌人。
- 小妖：沿路径移动，接触唐僧后攻击。
- 波间升级：前两波结束各选择一次；第三波结束后直接结算。
- 升级候选：金箍棒扩大悟空攻击范围、紧箍咒短暂定身、三昧真火造成持续伤害。具体触发和叠加方式在开发时明确并验证。
- 开始界面、放置提示、血量与波次显示、升级选择、胜负和重新开始。

角色使用几何图形占位。第一版不要求制作正式美术、音效、账号、存档或完整八十一难。
