# 西游肉鸽塔防

一款以西游取经为主题的网页肉鸽塔防游戏。玩家守护地图中央的唐僧，布置徒弟抵御妖怪，并在每波战斗结束后选择法宝或神通，逐步形成不同的战斗组合。

**当前阶段：策划与原型准备。** 第一周目标是完成可玩的一局：两个角色、三波敌人、波间三选一升级，以及胜负结算。游戏尚未开发，文档中的数值为初始设计，需试玩后调整。

- [游戏方案](docs/game-design.md)
- [第一周开发计划与 Bot 分工](docs/sprint-1.md)

原型计划使用 HTML5 Canvas 和原生 JavaScript，使用简单几何图形占位，通过浏览器运行。后续扩展更多角色、法宝和关卡，取决于原型试玩反馈。
